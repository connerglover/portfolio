# Digital Electronics deliverable theme

One look for DE PDF deliverables: decks and separate answer sheets. This theme must never be used to make a PDF write-up. Portfolio write-ups are simple supplementary `write-up.md` or `.txt` prose rendered directly on the website, with context and extra media absent from the slideshow; they do not repeat the slides. PDF titles use larger dark text on white, with no decorative header, dark banner, colored title, or boxed metadata block. Keep identifying details small and plain. This follows the workspace-wide PDF appearance rule in root AGENTS.md. Body diagrams and evidence may retain useful colors. Refine the theme here, never inside a package.

| File | Use |
|---|---|
| `de-deck.scss` | reveal.js theme for `presentation.qmd` |
| `de-doc.css` | US Letter print stylesheet for separate `answers.qmd` only; not website write-ups |
| `fonts.css` | Generated by `build_fonts.py`: every font as an embedded data URI |
| `fonts/` | Font files and their SIL Open Font License texts |

**Faces:** Archivo, variable width and weight, for display (`DE Display`); IBM Plex Sans for text (`DE Text`, with a Greek subset for Ω); IBM Plex Mono for values and labels (`DE Mono`); STIX Two Math for MathML formulas (`DE Math`).

**Palette:** paper `#f2efe6`, ink `#13202b`, signal `#e0502a`, trace `#0e7f7b`, amber `#f2b134`, night `#0f1a24`.

## Deck front matter

```yaml
pagetitle: "<activity> <title>"
format:
  revealjs:
    theme: [default, ../_theme/de-deck.scss]
    css: ../_theme/fonts.css
    width: 1920
    height: 1080
    margin: 0
    center: false
    slide-number: c/t
    show-slide-number: all
    transition: none
    pdf-max-pages-per-slide: 1
    slide-level: 2
    controls: false
    progress: false
    embed-resources: true
    html-math-method: mathml
    include-in-header:
      text: "<style>:root { --dwg: 'DWG <activity> · <short title>'; }</style>"
```

Separate answer sheets use `format: html` with `minimal: true`, `embed-resources: true`, `html-math-method: mathml`, `css: [../_theme/fonts.css, ../_theme/de-doc.css]` and the same `--dwg` header line. Do not give supplementary website write-ups a PDF-design source or print them.

## Building and printing

```sh
cd "<package>" && quarto render presentation.qmd
node .school/scripts/print_pdf.cjs deck ".school/quarto-out/<package path>/presentation.html" "<package>/presentation.pdf"
node .school/scripts/print_pdf.cjs doc  ".school/quarto-out/<package path>/answers.html"     "<package>/answers.pdf"
```

Then look at every page, and check the PDF's embedded fonts: nothing should fall back to a system font such as Arial or Cambria Math.

## Rules learned the hard way

- **Keep slides inside 1080 px, less the bottom band.** Keep content above about 960 px so it clears the title block. `pdf-max-pages-per-slide: 1` makes each slide print as exactly one page, so anything that overflows is clipped, not moved to a new page.
- **Never start a div with a Markdown heading** (`###`). Pandoc turns that div into a nested `<section>`, and reveal.js makes it a separate vertical slide. Use raw `<h3>…</h3>` inside layout divs.
- **Include SVG figures inline** with `{{< include assets/x.svg >}}` on its own line, inside a fenced div rather than raw HTML, so they use the embedded fonts. An SVG in an `<img>` falls back to system fonts. Generated SVGs must have no blank lines.
- **Never uppercase text that can hold units.** CSS uppercase turns µ into a capital Mu, which reads as M ("22 MF"). Uppercase is only for fixed labels.
- **Avoid glyphs outside the fonts**, such as ⅔ or →. Write 2/3, or draw the symbol.
- **The layout helpers are** `.cols` (`.w37`, `.w46`, `.w64`, `.w73`, `.center`), `.stack`, `.fig` (`.bare`), `.readouts`/`.readout`, `.gap-box` with `.gap-label` for missing evidence, `.map` for the rubric map, `.caption`, `.lede`, `.small` and `.muted`. Use `{background-color="#0f1a24"}` for dark bench slides.
- **Every deck ends with the RWL slide** (Right, Wrong, Learned) in Conner's own words. It uses the `.rwl` layout: three `.rwl__col` blocks with `.rwl--right`, `.rwl--wrong` and `.rwl--learned`, each holding a `.rwl__letter`, a raw `<h3>` and the text. If he hasn't given his RWL yet, use a `.gap-box` placeholder instead.
- **Muted "calculated" columns:** give reference columns `th.calc`/`td.calc` so measured values lead. `table.compare` is the small scope-versus-calculated table.
- **Blank RWL** (Conner writes it himself): put `<div class="rwl__lines"></div>` in each column in place of the text. The README handoff lists the RWL as missing.
